## F-311: Dead skip guards can only hide regressions (conditions always false in repo)

**Severity:** medium (X1 is the biggest silent-coverage risk; priority)
**Status:** open
**Found in:** see list
**Affects:** unit / room-correction / e2e-harness coverage, testing-process.md Sec 9.2
**Found by:** quality-engineer (pytest.skip audit, 2026-10-24)

### Description

Each skip below guards a condition that is always false in the repo. It
cannot protect against anything and can only hide a regression. Fix:
delete the guard, or replace it with an assert.

- **X1 (priority):** module-level `except ImportError: pytest.skip(allow_module_level=True)`
  in `src/web-ui/tests/unit/test_speaker_lifecycle_integration.py:27`,
  `unit/test_filter_routes.py:35`, `unit/test_activate_integration.py:33`,
  `unit/test_speaker_routes.py:37`, `unit/test_protection_integration.py:63`.
  `app/speaker_routes.py` and `app/filter_routes.py` exist. If an import
  breaks, the whole file skips and CI stays green. These must become hard
  imports.
- **X2:** `unit/test_protection_integration.py:127` (profile `bose-home-chn50p.yml`
  exists), `:478`, `:488` (`pw_config_generator.py` exists).
- **X3:** `integration/test_full_user_journey.py:181` skips on HTTP 500 citing a
  numpy bool serialization bug that appears fixed (`filter_routes.py:124-128`).
  Any 500 is hidden.
- **X4:** `src/room-correction/tests/conftest.py:75-131`: dead CamillaDSP
  fixtures (D-040). Remove them.
- **X5:** `src/room-correction/tests/test_driver_validation.py:608, 614, 637`
  (`configs/drivers/` and `TEMPLATE.yml` exist).
- **X6:** `tests/e2e-harness/conftest.py:202, 387`, `tests/e2e-harness/test_sim_harness.py:124, 180`
  (`room_config.yml`, `small_club.yml` exist).
- **X7:** deterministic computations that skip instead of asserting a
  precondition: `src/room-correction/tests/test_transient_fidelity.py:622`
  (near-zero energy is a bug) and `unit/test_protection_integration.py:641`
  (Xmax for fixed T/S params is deterministic).
