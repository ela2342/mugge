## F-362: Silent ImportError module skips hide whole test modules

**Severity:** high (quality-engineer; security-specialist: security-relevant)
**Status:** open. Not a US-163 blocker; defined and dispositioned in the PR #50 body (AD M1). Still open at `9b2879eb` (QE)
**Found in:** `src/web-ui/tests/unit/test_filter_routes.py:34-35` (`pytest.skip(..., allow_module_level=True)` on ImportError); four more modules with the same guard
**Affects:** CI and local test evidence for the web UI; S-001 path traversal regression tests; D-009 interlock tests on deploy/rollback
**Related:** F-372, F-037, F-301, F-302, F-303–F-311, S-001, D-009, US-163
**Found by:** worker-2 (F-335 work); confirmed by quality-engineer (2026-10-25); root cause by security-specialist

### Description

`test_filter_routes.py` wraps its imports in a try block and skips
the whole module on ImportError. The log shows only "collected 903
items / 1 skipped": that one skip is the whole module, so 0 of its 85
tests run, and nothing marks it as a failure.

Root cause (security-specialist): the test imports `_PROFILES_DIR`,
which `filter_routes.py` no longer defines (it is now
`_profiles_dir()` at `:54`), so the ImportError is permanent.

The skip silences `TestDeployPathTraversal` (the S-001 regression)
and the D-009 interlock tests on deploy and rollback. These guard an
unauthenticated LAN endpoint (F-037).

Observation only: the other four guarded modules ran in the same
session (speaker_lifecycle_integration 17, activate_integration 22,
speaker_routes 177, protection_integration 30 tests), but their
guards would still mask an import failure the same way.

### Acceptance criteria

1. `test_filter_routes.py` imports what `filter_routes.py` actually
   defines; all its tests are collected and run.
2. The S-001 (`TestDeployPathTraversal`) and D-009 interlock tests
   run and pass in CI, with a non-zero count in the log.
3. An import failure in a test module fails the run; it never
   becomes a skip. This applies to all five guarded modules.
4. A mutation check: breaking an import in one of the modules makes
   the run fail (QE).
