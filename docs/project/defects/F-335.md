**Severity:** critical (quality-engineer; team-lead filed it as high, QE raised it: blocks every merge)
**Status:** open — architect diagnosing; fix needs a worker (O-8)
**Found in:** `nix run .#test-all` in CI (cd into `<flake source store path>/src/web-ui`: "No such file or directory")
**Affects:** Rule 13 (CI green), O-22, every PR including #41-#43, the QE Gate 1 evidence run (F-256, F-272, US-142..153)
**Related:** F-329 (no durable CI evidence), F-330 (paths filter skips tests), F-333 (T3 not in PR CI); O-22
**Found by:** change-manager and quality-engineer (dispatched T1 runs for O-22, 2026-10-24)

### Description

`test-all` fails before any test runs: it cannot cd into `src/web-ui` in
the flake source store path. Dispatched runs 40099078614 (PR #42) and
40099080404 (PR #43) are main plus docs-only changes (`c34f7da7`), so the
defect is on main. Logs: `/tmp/mugge-ci-logs/dispatch-*` (dev machine).

Suspected cause (unverified, architect diagnosing): `flake.nix` uses
`toString ./.` at 29 test-app sites, and the unpinned CI Nix is now
2.35.4. If so, the environment drifted since April, when CI was green.

### Impact

- No PR can get a green T1, so all merges are blocked, #41-#43 included.
- CI on main is unverified since an unknown point.
- The Gate 1 evidence run (F-256, F-272, US-142..153) is blocked.
- Under the old skip rule, docs PRs would have kept merging "green" while
  main's tests could not run at all (F-330). This is the case O-22 guards.
