## F-300: Minimum-phase verifier is a heuristic proxy (90% energy / 10% peak)

**Severity:** low
**Status:** open
**Found in:** `src/room-correction/room_correction/verify.py` (min-phase check)
**Affects:** design principle 3 (transient fidelity), F-262
**Found by:** architect (F-262 review, 2026-10-24)

### Description

The min-phase check passes if 90% of the energy lies in the first half and
the peak lies in the first 10%. This is only a rough proxy, and it can pass
filters that are not minimum-phase.

### Fix

Replace it with an energy-delay comparison against a trusted reference.
Base the tolerance on data from the F-262 diagnostic run. Keep the
90%/10% heuristic only as a sanity check. The reference must be
independent of the code under test (see F-262 condition 4).
