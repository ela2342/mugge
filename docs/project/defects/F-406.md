## F-406: Filter rollback E2E skips when the versions listing shows no active v1, so rollback goes untested

**Severity:** unrated (P-level pending, PM)
**Status:** open. Found by the `-rs` skip summary added in PR #64 (F-362)
**Found in:** `src/web-ui/tests/service-integration/test_filter_deploy_e2e.py:315` (`test_rollback_restores_previous_version`), CI run 40333713247 at `f715538e` (2026-10-26)
**Affects:** CI evidence for filter rollback (`/api/v1/filters/rollback`); D-009 rollback path
**Related:** F-362, F-402, F-405, F-407, F-394
**Found by:** quality-engineer (PR #64 skip review)

### Description

The test generates and deploys v1, reads `/api/v1/filters/versions`, and
collects the timestamps of entries marked `active`. It then generates and
deploys v2 and asserts that the active set changed. Before the rollback it
does:

```python
if not v1_timestamps:
    pytest.skip("No v1 timestamp found in versions listing")
```

In CI run 40333713247 this skip fired: `SKIPPED [1]
tests/service-integration/test_filter_deploy_e2e.py:315: No v1 timestamp
found in versions listing`. v1 had just been generated and deployed
(`d1["deployed"]` asserted), so an empty active set in the versions
listing is not an environment limit. It is a product, API contract or
test-key defect (quality-engineer). The rollback call and its asserts
never run, so CI has no rollback evidence while the test reports SKIPPED,
not FAILED.

### Acceptance criteria

Proposed by the technical writer from the QE's PR #64 ruling; the QE
confirms or amends them.

1. Root-cause why the versions listing shows no `active` entry right
   after the v1 deploy: the product (deploy does not mark the version
   active), the API contract (other field or key name), or the test (wrong
   key or shape).
2. Fix the cause. The test gets v1's timestamp without the skip path;
   a missing v1 timestamp after a successful deploy is a FAIL.
3. The rollback asserts run in CI: the `-rs` output of the E2E step shows
   no skip for `test_rollback_restores_previous_version`, and the test
   PASSED.
