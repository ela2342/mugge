## F-339: GM CloseGate reports success when the convolver node is missing and nothing was zeroed

**Severity:** high (audio-engineer: the gate reads CLOSED with no gain write; part of the F-320 authority problem). Confirmed by architect in code: `main.rs:824-843`, `set_node_param_mult` is fire-and-forget with no read-back.
**Status:** open — fixed by US-159 G11/T10 (architect)
**Found in:** `src/graph-manager/src/main.rs` `CloseGate` handler (returns Ok and sets the state to closed even when the convolver node is not found)
**Affects:** F-320, D-063, US-159 G1/G4/T8, safety.md pre-flight #10
**Related:** F-320, F-338, F-298
**Found by:** audio-engineer (2026-10-24, while verifying F-338)

### Description

CloseGate sets the gate state to closed and returns Ok even when the
convolver node isn't found and no Mult was written. The UI and API then
report a closed gate that was never closed.

### Acceptance criteria

1. CloseGate reads back all 8 Mult values after writing and returns an
   error unless all read 0.0.
2. If the convolver node is missing, CloseGate returns an error and the
   state is not reported as closed (US-159 decides the exact state name).
3. A real-stack test covers the missing-node case (US-159 T1, T10).
