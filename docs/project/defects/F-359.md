## F-359: GraphManager set_mode changes links mid-stream while the gate is Open

**Severity:** high (audio-engineer; architect, static)
**Status:** open — static analysis only, nothing run. Fix: US-159 G15 (PO adopted, 2026-10-24). Interim: status.md rule 1 (close the gate before every mode change)
**Found in:** GM `handle_set_mode` (`src/graph-manager/src/rpc.rs`); no gate-state check before the link changes
**Affects:** every mode change with the gate not Closed; amps, HP/IEM ch 5-8
**Related:** F-342 (same handler, Live-mode IEM feed), F-314 and US-159 G7 (same refusal pattern for `set_venue`), F-358 item 3, D-054, D-063
**Found by:** audio-engineer (2026-10-24), confirmed statically by architect

### Description

`set_mode` re-links the graph without requiring the gate to be Closed
and without a ramp. In Opening or Open, the link change is a step
discontinuity into the amps, and with F-342 a different feed reaches
the IEM on ch 7-8 at level.

### Acceptance criteria

1. GM's `set_mode` is refused unless the gate is Closed (AE: refuse, no
   automatic close). US-159 G15.
2. US-159 T58-T60 pass.
3. Interim, until fixed: the gate is closed before every mode change
   (status.md rule 1; safety.md wording per TW).
