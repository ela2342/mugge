## F-293: GraphManager seccomp filter blocks sched_setscheduler

**Severity:** low (latent — currently harmless per code comment)
**Status:** fixed (commit `991ff456`, 2026-04-19, PR status unknown)
**Found in:** `nix/nixos/services/graph-manager.nix`
**Affects:** standalone
**Found by:** unknown (no original record)

> **Reconstructed record (PM, 2026-10-24).** Derived from commit `991ff456`
> and the code comment in `graph-manager.nix`. Never filed.

### Description

The GraphManager unit's `SystemCallFilter` excluded `~@privileged`, which
blocks `sched_setscheduler` at the seccomp level. Harmless today because
systemd applies FIFO before the filter is installed, but would break if
systemd changes exec ordering or GM needs runtime RT promotion.

### Fix

`~@privileged` removed; `SystemCallFilter = [ "@system-service" ]`,
`NoNewPrivileges=true` kept. Code comment states Security Specialist
approved "Option A". Approval not recorded in tracking.
