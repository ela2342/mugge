## F-331: 16k-tap dirac on ch 5-8 roughly doubles convolver CPU load

**Severity:** low (CPU budget; needs Pi measurement)
**Status:** open — owner of analysis: architect
**Found in:** production filter-chain conf (D-063 / US-115: ch 5-8 through the convolver with 16384-tap `dirac.wav`)
**Affects:** CPU budget (BM-2 baseline was 4 channels), DJ mode headroom
**Related:** D-063, US-115, US-116 (per-channel delays), BM-2
**Found by:** architect (2026-10-24)

### Description

D-063 routes ch 5-8 through the convolver with a 16384-tap identity filter.
That adds four full-length partitioned convolutions doing identity work,
roughly doubling FFT load compared with the 4-channel BM-2 baseline the CPU
budget is based on.

### Options

- A 1-tap (or short) dirac: equivalent output, nearly free.
- If US-116 per-channel delays need taps on ch 5-8, size the filter to the
  maximum delay, not 16k.

### Acceptance criteria

1. BM-2 rerun at 8 channels on the Pi (CM session) before any change.
2. Filter length on ch 5-8 chosen from that data and the US-116 delay need.
3. BM-2 rerun after the change shows the expected reduction, no audible
   difference on ch 5-8.
