## F-360: A web UI crash or restart mid-measurement leaves measurement mode with the gate Open

**Severity:** high (PO, from AE's A3; architect and AE own the fix)
**Status:** open — static analysis only, nothing run. Fix: US-171 (GM measurement lease), directly after US-160. Interim: status.md rule 1 (web UI lost during a measurement: amps off and HP/IEM off first)
**Found in:** web UI measurement session and TF mode (`session.py`, `transfer_function_mode.py`): the restore runs in the web UI process; GM holds no lease on the measurement
**Affects:** measurement and TF runs; amps, HP/IEM ch 5-8
**Related:** F-320 E (same class), F-359, F-349, US-160 AC10-AC12, US-171, D-063
**Found by:** audio-engineer (A3, 2026-10-24)

### Description

Measurement and TF runs need the gate Open while signal-gen plays
(GM `routing.rs:649-679`). If the web UI crashes, restarts or loses its
GM connection mid-run, nothing closes the gate or restores the mode: GM
stays in measurement mode with the gate Open. US-160's restore paths
run in the web UI, so they do not cover this.
