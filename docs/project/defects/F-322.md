## F-322: Per-speaker thermal / excursion limits are not enforced on runtime gain

**Severity:** high (audio-engineer)
**Status:** open
**Found in:** `src/graph-manager/src/gain_integrity.rs` (enforces only a global Mult ≤ 1.0); speaker profile `power_limit_db` is declarative only
**Affects:** D-009, D-029, D-031, US-155, US-089
**Related:** F-314, F-321, F-037, F-299
**Found by:** audio-engineer (US-155 retroactive review, 2026-10-24)

### Description

The CHN-50P is rated at 7 W, which is -18.1 dB re 450 W. The profile's
`power_limit_db: -22` is never enforced. The UI soft cap (-20 dB) happens
to stay below the CHN-50P limits, but three paths allow 0 dB (450 W into a
7 W driver): the API, venue files (foh-passthrough runs at unity), and the
F-314 hot switch.

### Fix (AE)

gain_integrity enforces a per-channel max Mult, derived from the venue's
speaker identity and amp (D-029 framework).

### Severity rationale (audio-engineer, 2026-10-24, answering an AD challenge)

F-322 stays **high**, conditionally. The critical bar is a speaker-damage
path reachable through routine operator use without warning, or remotely
without auth. F-322 on its own has neither:

1. Routine UI use stays below the CHN-50P limits. The UI soft cap is
   -20 dB re Mult 1.0: under the worst case Mult 1.0 = 450 W that is 4.5 W,
   below the 7 W thermal limit (-18.1 dB) and the dirac/no-crossover Xmax
   point (-17 dB). Margin about 2-3 dB; no amp clipping at that level. The
   UMII18-22 needs no ceiling. The margin assumes F-299 is fixed (overshoot
   bounded to <= -0.5 dB); until then it is a fraction of a dB less. D-009
   is cut-only, so room correction adds no other boost.
2. Every path that exceeds the limit is already Critical in its own defect
   or covered by an interim rule: the F-314 hot switch (Critical), the
   unauthenticated crafted API call (F-037, Critical), foh-passthrough
   with amps on (F-271, interim rule 3). F-322 is the missing
   defence-in-depth layer behind those; rating it Critical too would
   double-count the same paths.

**Re-rates to critical if any of these holds:**

- (a) A UI path (venue editor, venue import/upload, profile edit) can set
  a channel gain above -20 dB without the soft cap. Not verified: code-read
  check for QE or architect.
- (b) The UI soft cap is raised.
- (c) A speaker profile is added rated below about 4.5 W re 450 W on a
  mains-role channel, or below about 18 W on a summed (sub) channel
  (amended after an AD caveat: the subs receive L+R summed, so correlated
  content arrives up to +6 dB hotter than the Mult value).
- (d) F-314 or F-037 is downgraded or closed before F-322 is fixed, making
  F-322 the primary path.
