## F-329: CI keeps no durable test evidence — Rule 13 "CI green" not auditable after log expiry

**Severity:** medium (process; quality-engineer)
**Status:** open
**Found in:** `.github/workflows/ci.yml` (no test report artifacts)
**Affects:** Rule 13 (CI green), VERIFIED transitions for F-256, F-272, US-142..US-153
**Related:** F-312 (green with stack down), F-330 (paths filter)
**Found by:** quality-engineer (2026-10-24), after change-manager found all April CI logs expired (HTTP 410)

### Description

CI uploads no test reports. Once GitHub's log retention runs out, only run
metadata remains, and a green conclusion does not show whether tests ran
or skipped (the F-312 risk). Evidence for F-256 (run 23999428556), F-272
(24077985724) and US-142..153 (24070153161) is lost for that reason.

### Acceptance criteria

1. Every test job writes junit XML and the `pytest -rs -rx` summary (or
   equivalent for Rust/other suites) as a workflow artifact.
2. The skip/xfail summary is also posted to the PR (comment or committed
   file) so it survives artifact retention.
3. Verified on one PR: the artifact lists every skip and xfail with reason.
