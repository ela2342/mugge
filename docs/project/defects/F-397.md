## F-397: Gain readback consumers show 0 on suspended or never-run nodes

**Severity:** P1 (architect; a safety display, Addendum 1 C)
**Status:** open
**Found in:** Gate-2 r6b joint ruling, section 2 (2026-10-26)
**Affects:** every gain readback consumer: the web UI config/gain display, GraphManager
**Related:** F-395, US-176
**Found by:** architect (owner), joint r6b ruling; raised to P1 by audio-engineer and architect (Addendum 1 C)

### Description

Every gain readback consumer shows 0 for a suspended or never-run node,
even when the real gain is non-zero (same reader blindness as F-395). A
node can show "muted" and surprise the operator when it resumes.

### Acceptance criteria

1. All gain readback consumers are audited.
2. They label or refuse a readback on any node that is not idle or
   running.
3. Once the canary (US-176) exists, consumers use it through one shared
   validator (the F-391 rule) and do not re-implement the state check
   per consumer.
