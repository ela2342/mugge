## F-364: local-demo seeds are read-only, so saving a profile fails

**Severity:** low
**Status:** open
**Found in:** `scripts/local-demo.sh:676-680` (`cp -n` from the store keeps mode 0444); `src/web-ui/app/speaker_routes.py:136`; `src/web-ui/app/hardware_routes.py:120`
**Affects:** local-demo; tests that save a profile against local-demo
**Related:** #49 follow-ups (0444 seeds)
**Found by:** worker-2

### Description

local-demo seeds its config files by copying them from the Nix store
with `cp -n`. The copies keep the store's mode 0444, so a later
`write_text` (saving a speaker or hardware profile) fails with
EACCES.

### Acceptance criteria

1. Seeded files are writable by the local-demo user (for example
   `install -m 0644` or a `chmod u+w` after the copy).
2. Saving a profile in local-demo succeeds; a test covers it.
