## F-350: Stale comments claim the convolver reload destroys the node and re-reads conf.d

**Severity:** low (code comments; misled a review)
**Status:** open — fix with F-346 (AE) or on its own; needs a worker (O-8)
**Found in:** `measurement/session.py:1258-1261` (comment) and `:1286-1287` (`_reload_convolver` docstring); `filter_routes.py:580`; the `/reload-pw` route docstring (AE)
**Affects:** code readers and reviewers
**Related:** F-346, F-348 (AC12)
**Found by:** architect, AE, AD (2026-10-24), after TW's F-348 note

### Description

The comments say the reload destroys the convolver node so that PipeWire
re-reads conf.d. The code delegates to `deploy.reload_convolver`
(`deploy.py:392-437`), an in-place `Reload` swap that keeps the node (ID
checked unchanged) and does not re-read conf.d. The stale text led to a
wrong F-348 finding, since withdrawn.

### Acceptance criteria

1. The comments and docstrings describe the in-place swap.
2. The `/reload-pw` route docstring matches what the route does.
