### Description

PipeWire hit the default kernel RT throttle (`sched_rt_runtime_us` = 95%)
under sustained load, causing periodic scheduling delays and xruns. In
addition, hardening directives in the base PipeWire user unit
(`SystemCallFilter`, `SystemCallArchitectures`, `LockPersonality`,
`MemoryDenyWriteExecute`) each force `NoNewPrivileges`, which prevented
`CPUSchedulingPolicy=fifo` from taking effect.

### Fix

- `kernel.sched_rt_runtime_us = -1` (throttle disabled on PREEMPT_RT) and
  CPU governor `performance` — new module `nix/nixos/rt-tuning.nix`.
- PipeWire unit hardening directives cleared so FIFO/88 applies.
- Code comment states Security Specialist approved. **Not confirmed:** security-specialist has no record of this approval (2026-10-24). Do not treat it as approved.
