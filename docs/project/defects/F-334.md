**Severity:** medium (mock-boundary divergence; F-318 cannot be reproduced locally)
**Status:** open
**Found in:** `scripts/local-demo.sh:208` (`policy.standard = disabled`)
**Affects:** D-057 (mock boundary), D-065, F-318 testability, US-159 B1/B2/T6

### Description

Production removed `policy.standard = disabled` under D-065, because it
broke node activation (F-292). local-demo still sets it, so local-demo runs
a WirePlumber linking policy production no longer uses. The F-318 auto-link
path therefore cannot be reproduced or regression-tested in local-demo.

### Acceptance criteria

1. local-demo uses the same WirePlumber policy configuration as production
   (shared source, not a copy), or the divergence is a documented,
   architect-approved exception.
2. A local-demo test exercises the F-318 path (default-sink stream must
   deliver zero frames to the USBStreamer ports), complementing the Pi test
   in US-159 T6.
