### Description

`90-no-auto-link.conf` set `policy.standard=disabled`. This disabled all
WirePlumber format negotiation, not just auto-linking, so nodes were not
activated and ports were not created.

### Fix

D-065: `90-no-auto-link.conf` removed. Remaining anti-bypass layers are
`node.autoconnect=false` plus GraphManager reconciler cleanup.
