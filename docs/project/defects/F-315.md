## F-315: D-063 gate-open cosine ramp collapses to an instant step

**Severity:** medium (audio-engineer)
**Status:** open
**Found in:** `src/graph-manager/src/main.rs:789-806`
**Affects:** D-063 (3 s / 30 x 100 ms ramp), US-113
**Related:** F-314, F-298
**Found by:** technical-writer (safety.md D-063 drift check), confirmed by audio-engineer (2026-10-24)

### Description

All 30 cosine ramp steps are applied within one PipeWire main-loop
iteration, so opening the gate is in effect an instant step to the venue
gains. D-063 specifies a 3 s ramp (30 steps x 100 ms).

### Fix

A real temporal ramp, timer-driven across graph cycles. A test must
observe intermediate gain values over time (not just the end state).
