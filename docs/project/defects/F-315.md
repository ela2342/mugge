## F-315: D-063 gate-open cosine ramp collapses to an instant step

**Severity:** medium (audio-engineer)
**Status:** open
**Found in:** `src/graph-manager/src/main.rs:789-806`
**Affects:** D-063 (3 s / 30 x 100 ms ramp), US-113
**Related:** F-314, F-298; **fix story:** US-159 (G2)
**Found by:** technical-writer (safety.md D-063 drift check), confirmed by audio-engineer (2026-10-24)

### Description

All 30 cosine ramp steps are applied within one PipeWire main-loop
iteration, so opening the gate is in effect an instant step to the venue
gains. D-063 specifies a 3 s ramp (30 steps x 100 ms).

### Fix

A real temporal ramp, timer-driven across graph cycles. A test must
observe intermediate gain values over time (not just the end state).

### Audio-engineer ramp ruling (2026-10-24; proposed D-063 amendment, pending owner decision O-27)

One slew limiter for ALL gain increases (open() and gain increases while
Open) at 30 dB/s (about 2 s full open, starting from -60 dB relative to
target), wall-clock dt, max +3 dB per tick, the same relative curve on all
channels, target validation 0 <= Mult <= 1.0, and an active zero write on GM
startup. Resolved by the same design as F-314 (US-159 G2, test T2). D-063's
ramp text needs an amendment once this lands (architect / technical-writer).

### Ramp curve: owner decision O-27 (audio-engineer, 2026-10-24)

The 30 dB/s / 2 s slew above deviates from D-063's 3 s cosine (30 x 100 ms),
so adopting it is a D-063 amendment and needs owner confirmation. AE's
actual safety requirement is: every increase is rate-limited on wall-clock
time, the per-tick cap and generation check hold, and a full open takes
>= 2 s. D-063's 3 s cosine, implemented over real time, is equally
acceptable to AE. The curve and exact duration are the owner's choice.
