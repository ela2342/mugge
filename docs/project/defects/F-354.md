## F-354: Config gain API splices the gain name into the pw-cli params, so a crafted name sets any Mult up to 10.0 (+20 dB), even with auth

**Severity:** critical (security-specialist, audio-engineer; architect confirmed; 2026-10-24)
**Status:** open — static analysis only (security-specialist; architect confirmed from PW `parse_params`). Worker to be assigned. Interim: status.md rules 7 and 11 [safety.md Rules 8, 11]; rule 7 tightening proposed (security, O-32). Owner notified (O-38)
**Found in:** `src/web-ui/app/pw_helpers.py:282-286` (`set_mult` builds the pw-cli params f-string; the only name check is `startswith("gain_")`), `config_routes.py:198-201` (`set_gain` writes unknown names)
**Affects:** all 8 gains, past the D-063 gate and `MULT_HARD_CAP`
**Related:** F-352 (same endpoint, NaN path), F-344, F-037 (no auth), US-110 (auth does not close it), US-159 (sole writer removes the path), D-009
**Found by:** security-specialist (2026-10-24)

### Description

The gain-name key from the request goes straight into the pw-cli params
f-string. The only name check is `startswith("gain_")`, so a crafted
name can inject SPA-JSON and set a deterministic Mult of up to 10.0
(+20 dB) on any of the 8 channels in one request, past the gate and the
1.0 cap. SPA JSON bare words also break out without quotes, so escaping
cannot fix it; only an exact name allowlist does (architect).

Contributing cause: `set_gain` writes unknown names, because
`find_gain_node` returns the convolver id with `mult=None`
(`config_routes.py:198-201`).

Reach: unauthenticated today (F-037). Still reachable by any
authenticated client after US-110, so enabling auth does not close it.
It needs no undefined behaviour and is deterministic (AE). Harm is the
same as F-352: full-scale clipping into the amps and the HP/IEM.

### Acceptance criteria

1. (Security, architect) Gain names are matched exactly against the
   fixed set of the 8 D-063 names; anything else is a 422, never
   escaped.
2. (AE) The pw-cli params are built structurally, never by string
   splicing.
3. (Security) A gain that is not found is an error; nothing is written
   (no write to the convolver id with `mult=None`).
4. (Security) `_set_mult_sync` and every other Mult writer re-validate
   the name, as F-352 AC2 does for the value.
5. (Security, AE) Test: POST with an injected key and with an unknown
   name each give a 4xx and nothing is written (pw-cli read-back).
6. (AE) US-159's sole writer removes this path; these ACs still apply to
   any writer that remains until then.
