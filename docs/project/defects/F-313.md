### Description

Nothing in `flake.nix` (test-all/test-unit), `scripts/test-e2e.sh`,
`scripts/test-integration.sh`, other `scripts/` or `.github/` references
these directories:

- `configs/pipewire/tests/test_filter_chain_config.py` asserts 4 `linear`
  nodes with Mult > 0.0 (l.121-134). This directly contradicts D-063 and
  would FAIL against the current conf (8 nodes at 0.0).
- `src/measurement/tests/` (`test_signal_gen_client.py`)
- `tests/e2e-harness/` (`test_measurement_workflow.py`, `test_pw_wiring.py`,
  `test_sim_harness.py`)
- `tests/integration/` (`test_levels_timestamp_monotonicity.py`,
  `test_gm0_link_survives_sigkill.sh`)

Caveat: some may be intentionally manual or Pi-only. No runner reference
was found for any of them.

### Fix (architect ruling, 2026-10-24)

- `configs/pipewire/tests/`: replace with the F-298 A7 static config test,
  wired into test-unit/test-all.
- `src/measurement/tests/`: wire into test-unit.
- `tests/e2e-harness/`: migrate to local-demo, then retire.
- `tests/integration/`: port, including the US-059 AC#1 GM-SIGKILL gate.
- Deleting a test needs QE approval (Sec 9.2). Failures on first run once
  wired in are real findings, not regressions.

### Detail: configs/pipewire/tests/test_filter_chain_config.py (QE)

It has 19 unittest tests and has gone stale against main, so wiring it in
as-is would turn CI red:
- `test_has_four_convolvers` expects 4 convolvers; the conf has 8.
- `test_four_channel_io` expects 4ch; the conf is 8ch (l.208, l.221).
- `test_linear_gain_nodes_exist` expects 4 nodes with Mult > 0.0, which
  contradicts D-063.
- The chaining/output tests (l.144, l.158) list only the 4 speaker gains.

Assertions that are still valid and must be ported:
- the drop-in has no protocol-native, client-node, adapter or rt modules;
- no gain, volume or bq_lowshelf labels;
- every convolver output chains into its linear node, and the filter-chain
  outputs are linear nodes (a static no-bypass check);
- coefficient paths;
- autoconnect disabled, passive playback, no suspend on idle;
- AUX positions;
- no context.properties or spa-libs.

### Acceptance criteria per directory (QE, on the architect's rulings)

1. **configs/pipewire/tests/**: fold into F-298 A7 (test-unit). Port the
   valid assertions, generalised to 8 channels, and apply them to both
   confs. Drop the stale ones. Delete the file. The worker supplies an
   assertion-to-A7 mapping. A7's mutation evidence also covers removing
   one `gain_X:Out` output.
2. **src/measurement/tests/**: test-unit runs them, with the collection
   count shown in the log. The rootdir/sys.path issue is resolved. No
   skips. Missing client tests are tracked separately as F-324.
3. **tests/e2e-harness/**: the worker produces an assertion-by-assertion
   mapping per file (ported to X / already covered by Y / dropped with a
   reason), and QE reviews it before anything is deleted. The 4 signal-gen
   tests move to service-integration against local-demo:
   - Level-above-cap rejection asserts both the RPC error and that no
     signal appeared (pcm-bridge level stays at the floor).
   - Emergency-stop asserts that the level falls to the floor within a
     bounded time, checked by polling.
   - Mutation evidence: raising the cap, or skipping the stop, must make
     the test fail.
   - Delete only after a grep shows no references to the harness modules
     or templates.
4. **tests/integration/**:
   - Levels-monotonicity becomes a pytest test that reads ports from the
     manifest.
   - GM-SIGKILL (US-059 AC1, a hard gate) runs on a fresh isolated
     instance (the same fixture as D-063 A3).
   - It SIGKILLs the real GM PID, after checking the PID really is GM.
   - After the kill, pw-dump must show the convolver→USBStreamer link set
     and all 8 Mults identical to before.
   - It polls through the stability window instead of sleeping.
   - On GM restart, the links are re-adopted without duplicates.
   - Mutation evidence: a GM change that tears down links on exit makes
     the test fail.
   - Delete the directory once done.

**Order:** the architect's order applies. The shared fresh-instance
fixture is test infrastructure and needs QE and architect review before
D-063 A3 or GM-SIGKILL builds on it.
