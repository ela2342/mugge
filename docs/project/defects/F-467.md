## F-467: GraphManager reports a persisted venue as active when its profile is not found

**Severity:** unrated (architect `bd68d14a`: "not a safety issue"; no P-level given)
**Status:** fixed (PR #72, head `69004e63`, merged to main as `d12661e3`, 2026-10-28; fix commit `afaba039`)
**Owner:** architect (fix design); audio-engineer asked for the fix (`16ab21eb` P2)
**Found in:** `src/graph-manager/src/main.rs` l.214-226 at `afaba039^`
**Affects:** `get_venue` after a GM start whose persisted venue, or the `PI4AUDIO_DEFAULT_VENUE` venue, no longer exists
**Related:** F-465 (fixed in the same PR as its own commit), US-123, US-113, D-063
**Found by:** architect, while ruling on the F-465 fix (`bd68d14a`)

### Description

At startup the GM restores the venue named in its persisted
`last-venue` file (US-123). If no venue file with that name was
found, the GM still set `active_venue = Some(name)` with empty gains.
Architect (`bd68d14a`), verbatim: "get_venue then reports a venue
that is not loaded. open_gate is guarded at l.768, so this is not a
safety issue, but it misreports state. Fix: None on a lookup
failure." Audio-engineer (`16ab21eb` P2): a false active venue would
give a false PASS on the F-465 AC3e `get_venue` read.

### Fix (architect `bd68d14a`, `4c7eceaa` P2; audio-engineer `16ab21eb` P2)

- The startup restore moved to `venue::resolve_startup_venue`
  (`src/graph-manager/src/venue.rs` l.299 ff. at `c607ebac`). A venue
  is active only if its profile loads. On a lookup failure the GM
  logs "US-123: persisted venue '...' not found: ... — starting with
  no venue" and starts with no venue.
- The same applies to the `PI4AUDIO_DEFAULT_VENUE` path (`venue.rs`
  l.316-322); no unit sets that variable (F-465).
- The persisted file is not deleted or rewritten.
- Test: `startup_unknown_persisted_venue_is_none_and_gate_refused`
  (`venue.rs` l.961 at `c607ebac`). `get_venue` reads no venue, the
  pending gains are empty, `open_gate` is refused with "no venue
  loaded", and the persisted file is unchanged.
- The fix was its own commit inside the F-465 PR, so it can be
  reverted alone (architect `4c7eceaa` P2). Its commit subject reads
  "F-465 ..."; the change is F-467.
