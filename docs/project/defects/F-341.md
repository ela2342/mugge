### Description

No netcat package is declared in `nix/`, and `-q` is a Debian netcat
option (OpenBSD and GNU netcat do not take it, or treat it differently).
If `nc` is absent or does not accept `-q1`, the pre-flight checks for the
signal generator fail or hang, and the -20 dBFS cap cannot be verified as
written.

### Acceptance criteria

1. A CM OBSERVE session records whether `nc` exists on the Pi image, which
   implementation it is, and whether `-q1` works.
2. If not: either add the right netcat to the NixOS image, or rewrite the
   commands with a tool that is present (e.g. a small client shipped with
   signal-gen), on main and on `docs/safety-d063-gate`.
3. Every safety.md command is run once on the Pi and its expected output
   recorded. QE plan (Gate 2 style, run by a worker; covers Rules 5-8 and
   pre-flight #3/#6, `nc -q1` and the bash `/dev/tcp` fallback, for GM RPC
   `watchdog_unlatch`/`close_gate` and the signal-gen status):
   (a) CM OBSERVE: `command -v nc curl bash`, the nc variant, and a
   read-only signal-gen status query via each documented form, each
   returning a JSON line.
   (b) CM CHANGE, amps OFF, owner warned (O-2): `close_gate` via REST
   (curl) and via RPC, each followed by pre-flight #10 (8 Mults at 0.0 via
   `pw-cli enum-params`) as the independent oracle.
   (c) (QE) The exact #10 `pw-cli enum-params` command and its output
   format (`Float 0.000000`, and how nan/inf print) are verified on the
   Pi in the (a) session.
   TW then lists only the working forms in safety.md. Can run alongside
   the pending F-318/F-319/F-321 sessions.
   Re-scoped (QE, 2026-10-24): on the Pi 5 after US-163 T52 passes,
   never on Raspbian (other PW build, none of our services). Run (c)
   first: if the deployed pw-cli format differs, #10 is revisited
   before any other AC3 result is accepted. Evidence in the US-163 lab
   note or an F-341 lab note, with the commit and the PW store path.
4. The "not yet verified on NixOS" labels on the nc/bash commands in
   safety.md (§5 command block, Rule 5) are removed once 1-3 pass, so they
