### Acceptance Criteria

- [ ] AC1: AE reviews the 200 Hz crossover and signs off on the frequency, the 24 dB/oct slope and the satellite/sub summation, using the CHN-50P sealed data (Fc 157 Hz, F3 107 Hz, 7 W thermal limit). AE also confirms the sub mono sum L+R and normal polarity.
- [ ] AC2: D-031 for the satellites. The 200 Hz HPF baked into the FIR (D-055) meets or exceeds `mandatory_hpf_hz: 80`. AE verifies this against the actual coefficient files, not just the YAML.
- [ ] AC3: D-031 exception for the sub. The identity sets `mandatory_hpf_hz: null` and calls it an "owner directive", but no decision record exists. Either the owner confirms it and a decision D-NNN (amending D-031 for sealed and Xmax >= 16 mm) is filed, or a subsonic HPF is added. Must be settled before acceptance.
- [ ] AC4: Coefficient correctness. The venue references the shared names `combined_left_hp.wav`, `combined_right_hp.wav` and `combined_sub1_lp.wav`. When this venue is active, the loaded files must be the 200 Hz set from `scripts/generate-crossover-coeffs.py`, not leftover 80 Hz files from another profile. Needs a test or verification step. Risk: the 7 W CHN-50P could receive 80-200 Hz content.
- [ ] AC5: D-009 gain staging. AE confirms that mains -60 dB, sub -64 dB and spare -120 dB, together with profile `power_limit_db` (sat -22 dB, sub -6 dB) and headroom -7 dB, keep the CHN-50P under 7 W at full-scale input through the McGrey PA4504 (450 W @ 4 ohm). Arithmetic shown.
- [ ] AC6: Ch 4 (spare) stays silent with the D-063 gate open. Verified in local-demo.
- [ ] AC7: Config validation passes (`nix run .#test-all` driver/venue/profile validation), and the venue appears and loads in the web UI venue selector in local-demo. Browser E2E or a documented manual check.
- [ ] AC8: Stale text fixed. The CHN-50P identity comment says "Power limiting in CamillaDSP is essential" (D-040). The profile labels ch 6-7 as `hp2_*`, but the channel table calls them Singer IEM. UX/TW confirm naming.
- [ ] AC9: Rule 13 review on a PR (all 7 reviewers), even though the code is already on main. Issues found are fixed through a fix PR.
- [ ] AC10: Owner acceptance. A real-rig listening check is optional and the owner's call.
