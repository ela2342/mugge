## US-165: Minimal kernel config for bcm2712

**As** the owner running the Pi 5 kernel,
**I want** a minimal kernel config re-derived for the Pi 5 hardware (the US-114 equivalent),
**so that** the RT kernel carries no unneeded drivers.

**Status:** draft (PO, 2026-10-24; accepted by the architect)
**Priority:** low
**Depends on:** US-163, US-164
**Related:** US-114 (Pi 4 minimal config), D-013

### Acceptance criteria

- [ ] AC1: Config re-derived for the bcm2712 hardware; NVMe re-enabled if the Pi 5 boots from it.
- [ ] AC2: The US-164 measurements are repeated with the minimal config and do not regress.
