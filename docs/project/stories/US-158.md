## US-158: Live-Mode Mic Input Capture (F-295 follow-up)

**As** the engineer running Live mode (vocals + backing tracks),
**I want** the ADA8200 capture path (vocal mic ch 1, spare ch 2) available whenever Live mode is active,
**so that** the singer's mic reaches Reaper, the PA and the IEM without bringing back the F-295 dormant-driver problem in other modes.

**Status:** draft. Owner to confirm intent and priority (PO recommends high: since F-295 the production image cannot capture the vocal mic; tracked until now only in a code comment, `nix/nixos/audio/pipewire.nix:28-31`).
**Priority:** high (PO recommendation; owner to confirm)
**Depends on:** F-295 (root cause context), US-085 / D-061 (GM-managed lifecycle), US-106 (reconciler). Architect to confirm.
**Related:** F-323 (defect this story fixes), F-319 (level-bridge hw-in targets the removed node)
