## US-162: Dynamic per-speaker limiter

**As** the engineer running low-power drivers,
**I want** a dynamic limiter behind the static per-speaker ceilings,
**so that** program peaks and correlated sums cannot exceed a driver's thermal or excursion limit.

**Status:** draft (orphan from US-159 G9, filed by PM at PO request 2026-10-24). After a BM-2 CPU check (architect + AE).
**Related:** US-159 G9, F-322, F-331 (convolver CPU budget)

### Acceptance Criteria

- [ ] AC1: BM-2 CPU headroom check with the limiter in the graph (architect).
- [ ] AC2: AE specifies thresholds, attack and release per speaker profile.
- [ ] AC3: Real-stack test shows the limit holds for a correlated L+R sum on a summed channel.
