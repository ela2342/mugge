## US-171: GraphManager measurement lease closes the gate when the web UI is lost

**As** the engineer running a measurement,
**I want** GraphManager to close the gate on its own when the web UI dies or hangs mid-measurement,
**so that** a crash never leaves signal-gen playing into the amps with the gate Open (F-360).

**Status:** draft (PO, 2026-10-24; design by the architect, amended by AE M1-M5)
**Priority:** high, directly after US-160 (PO)
**Depends on:** US-160 (G-a, G-b, the G11 read-back)
**Related:** F-360, F-359, F-349, F-320 E, US-160 AC15 (banner), D-063
**Reviewers:** AE (veto, gate code), architect, QE, security (new RPC surface)

Scope (PO): its own story rather than part of US-160. US-160 already
absorbed G11; its R1-R6 stand without the lease; the lease adds a new
GM protocol plus a client heartbeat; interim rule 1 covers the gap
until then.

### Acceptance criteria

- [ ] AC1: The lease exists only in measurement mode, never in DJ or Live. A false lease loss fails safe (AE M4).
- [ ] AC2: A single token holder; heartbeat every 1 s; lost after 3 s; connection EOF as a fast path if the connection is persistent.
- [ ] AC3: On loss: a reduce-only CloseGate, the G11 read-back, and the latched fault `measurement_lease_lost`. No automatic mode switch. OpenGate is refused until the operator acknowledges. Acknowledging lifts only that refusal: the F-349 AC2 reset, the G11 read-back, pre-flight #10 and an explicit OpenGate under S-012 are still required (AE M3). A failed read-back raises the CloseFailed banner (US-160 AC15: "CLOSE FAILED — NOT CONFIRMED SILENT. All amps off (incl. HP/IEM), headphones off, IEMs out.").
- [ ] AC4: Stated limitation: gain 0 does not cover NaN (0·NaN = NaN; F-349).
- [ ] AC5: signal-gen has its own hard maximum duration, independent of GM (AE M2, mandatory; replaces the former optional item).
- [ ] AC6 (QE tests): kill -9 of the web UI with the gate Open; SIGSTOP of the web UI (hung); a second client tries to renew; OpenGate without a lease; the fault survives a web UI restart; SIGSTOP of GM with the gate Open, and signal-gen stops within its cap (AE M2). Each gain assertion reads PW raw bits.
