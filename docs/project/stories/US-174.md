### US-174b: first slice (architect; thresholds AE)

Input: the venue profile `configs/venues/markaudio-ultimax-200hz.yml`
(CHN-50P + Ultimax, 200 Hz, one sub, spare channel muted) and the
speaker profiles and identities it names. Chain: room_simulator (the 3
existing scenarios plus a new generic home-lab scenario) -> sweep ->
deconvolve -> correction -> crossover/combine -> export -> verify.
The owner's real room dimensions replace the generic home-lab
scenario when they arrive (owner list); nothing blocks on them.

- [ ] AC1: One CLI run (`runner.py --mock`) writes the WAV set the
  venue profile and `deploy.py` expect: combined_left_hp,
  combined_right_hp, combined_sub1_lp, plus dirac for the spare, HP
  and IEM channels. Each is 16,384 taps, 48 kHz, float32, with the
  names in `export.CHANNEL_FILENAMES`.
- [ ] AC2: The verify gates fail loudly: D-009 (no gain above 0 dB,
  with a boost cap; value AE), minimum phase / no pre-ringing (energy
  before the peak below a threshold; value AE), and format.
- [ ] AC3: Closed loop per scenario: the simulated room IR convolved
  with the generated filter deviates from the target by at most X dB
  over the band, versus the uncorrected deviation (X and the band:
  AE). Room-mode nulls are not boosted beyond the cap.
- [ ] AC4: Off-position robustness: a filter made from position A,
  evaluated at simulated positions B and C, is no worse than
  uncorrected by more than Y dB (Y: AE). Guards against
  over-correction.
- [ ] AC5: Transient fidelity: the group delay at the crossover meets
  the D-001 minimum-phase budget (about 1-2 ms), using the existing
  test_transient_fidelity.
- [ ] AC6: Time alignment: the estimated sub delay is within 1 sample
  of the simulator's ground truth.
- [ ] AC7: Channel identity (US-098 P1): no cross-contamination
  between channels.
- [ ] AC8: The tests run in the existing `test-room-correction` check
  and `nix run .#test-room-sim-e2e`, with no `flake.nix` change. A
  missing import FAILS, not skips (F-362 lesson).
