## D-070: Supervised home-lab first-session exception to the Pi 5 amps-on list (2026-10-25)

**Status:** ACCEPTED (owner, 2026-10-25; PO). The owner answered both
inputs it depends on: the target ("As a milestone yes, but I want the
room correction too.") and F-037 ("acceptable for home lab"). F-037
is accepted for home-lab amps-on use only, not for gigs. The
exception is usable only once its own safety.md change is merged
under Rule 13 (AE), and only with H set.

**Context:** The AMPS-ON PRECONDITION LIST (Pi 5) in safety.md gates
any amps, HP or IEM use of the Pi 5. Closing every row with a code fix
takes about 6-9 working days (architect). The owner wants a first DJ
session sooner (US-173). The audio engineer accepts interim operating
rules for most rows, but only with a hardware level cap on the amps
(precondition H): a 450 W amp channel on a 7 W CHN-50P means any
single software fault would otherwise destroy the driver.

**Decision:**
1. For a supervised home-lab session, named amps-on rows may be met
   by an interim operating rule instead of the full fix.
2. "The exception lists the replaced amps-on rows individually with
   their interim rule; valid only with H set and the owner present;
   expires per row as soon as the full fix is merged." (PO)
3. Not replaced, whatever the session: the F-321 check (sha256 of the
   loaded WAVs matches the generated files) and F-341 AC3 (AE).
4. H is not waivable. Without H, no interim rule under this decision
   applies.
5. Unsupervised use and any gig still need the full fixes. In
   particular F-338 and F-339 are closed before any gig or unattended
   use (row 14).

**Rationale:** With H set, the worst case of every remaining software
fault (a NaN full-scale burst, an instant gain jump, a USBStreamer
transient, a stray link) is "loud but within the driver ratings". A
supervised session with the owner at the amp switches bounds the
duration. Room correction is sound quality, not safety, so the
session uses crossover-only filters.

**Safety cost per replaced row (AE, all assuming H):** a USB bump means
silence and recovery needs amps off plus a PipeWire restart (F-373);
a Pi hang can leave a stuck buzz until the amps are switched off
(F-317/F-325); a stray stream plays without crossover at up to the H
cap (F-318, hence the link check); a NaN gives a full-scale burst at
the H cap (F-349); an operator error gives an instant jump to the
venue gains (F-314/F-320); anyone on the LAN can open the gate
(F-037); throttling causes clicks mid-session (thermal). Removing H
is not acceptable.

**Impact:**
- safety.md needs a documented "supervised home-lab first session"
  exception and an H row (TW, AE wording, own review).
- US-173 carries the session ACs.
