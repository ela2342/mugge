# Noise goldens (US-179 AC5c)

Raw little-endian f32, mono, first 4096 samples of signal-gen's white and
pink noise generators, for seeds 0, 1, 174 and levels 1.0, 0.1.

Generated by `src/web-rc/golden/`, which compiles
`src/signal-gen/src/generator.rs` unchanged:

    cd src/web-rc/golden && cargo run --release --locked -- ../fixtures/noise

Do not edit these files by hand. CI regenerates them and compares bytes.
